Drop image files here (jpg/png/webp), then reference them in the `CONFIG.photos`
array near the top of `../index.html`, e.g.:

```js
photos: [
  { src: "photos/breakfast.jpg", alt: "Breakfast at Auszeit" },
  { src: "photos/studio.jpg", alt: "Palavara Pottery Studio" },
],
```

Leave the array empty to keep the placeholder tiles.
